# Frontend handoff

Written by the build session for whoever builds `app/`. The build session does
not write in `app/`; it owns `programs/`, `ops/`, `tests/` and `scripts/`.

## The boundary

| owner | paths |
|---|---|
| frontend session | `app/**` |
| build session | `programs/**`, `ops/**`, `tests/**`, `scripts/**` |
| either, conflict-prone | `DONE.md`, `TASKS.md`, `OPEN-QUESTIONS.md` — append at the END of the file, never edit an existing entry, and commit that file alone |

Separate branches, both into `staging` by PR. `staging` rejects direct pushes.

## What `app/` consumes from the program

| thing | where | note |
|---|---|---|
| IDL | `target/idl/othello.json` | regenerated by `anchor build`; commit a copy under `app/` if you want the build to be standalone |
| program id | `DhZhSvtTh78ZK26MkVVpyeDYr4MuyTZSVrT5YEFqqrDT` | MACHINE-LOCAL. Changes at the devnet deploy (T23). Read it from the IDL's `address`, never hardcode it |
| real mint bytes | `tests/fixtures/{AAPLx,NFLXx,SPYx,NVDAx}.json` | real mainnet accounts, `dataBase64` plus recorded multipliers and provenance |
| refusal codes | the IDL's `errors` array | map by NAME, not by number |

`quote_valuation(raw, haircut_bps, max_price_age)` returns four u64s as return
data, little-endian in this order: `mult_fixed`, `fund`, `exec`, `h`. It is
read-only and needs no wallet.

## S1, the Split lab

`design/FLOWS.md:160` — "naive vault vs Othello side by side", plus a Recheck
action. It is the most demo-legible screen in the product and it needs nothing
from gate 2.

The numbers, all verified in `tests/t05-quote-valuation.spec.ts` against the
real NFLXx mint:

| | before the split | at the split second |
|---|---|---|
| clock | 1763337299 | 1763337300 |
| multiplier | 1.000000000 | 10.000000000 |
| wrapper price | 150 USDC | 150 USDC |
| share price | 150 USDC | 15 USDC |
| **Othello FUND** | 165 USDC | **165 USDC** |
| **Othello H** (haircut 2000) | 132 USDC | **132 USDC** |
| **naive FUND** (ignores the multiplier) | 165 USDC | **16.5 USDC** |

Position is 1.1 token = `110_000_000` raw. The naive column is
`raw x share_price / 1e8`, which is what a reader that ignores
`newMultiplierEffectiveTimestamp` computes. That is the whole story: same
position, same second, and the naive vault says the borrower lost 90%.

**The page must say which it is showing.** Recorded mainnet bytes from the
committed fixture, or live devnet. Do not let a reader assume live.

## Devnet, decided 2026-09-22

The four allowlisted mints are mainnet-only, so on devnet the program refuses
them. The demo will run on labelled MIRROR mints (S2, ADR-012). The site must
say the demo trades mirrors, not real xStocks. Real mainnet prices stay visible
through `/api/live`, display only, per ADR-007.

## Rules that are not negotiable

- Never invent a number. Real data or a clear error, per `AGENTS.md`.
- `design/` is read-only history. `design/FLOWS.md` §7 lists every place and its
  states; `design/UX-REVIEW.md` has the one STOP that was fixed.
- Neubrutalist, per `design/FRAME.md`.
- Every surface renders in light and dark.
- No secrets in client output; `scripts/check-secrets.sh` runs in CI.
